# KMITORA Client-Specific Demo Scenario Templates

Use `client_scenario_template.json` as the starting point for a new client demo.
The schema is `client_scenario_template.schema.json`.

Bundled cinematic presets:
- Banking & Financial Services
- Insurance
- Telecommunications
- Healthcare & Life Sciences
- Manufacturing
- Government / Public Sector

## Important demo boundary

A client-specific preset changes the narrative, systems, processes, risks, KPI
language, Digital Twin focus and specialist-agent emphasis. It does not turn a
reference-runtime result into client production evidence. Client evidence must
come from a client-specific validated run.
